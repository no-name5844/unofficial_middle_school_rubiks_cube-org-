# xssz 魔方非官方组织

> 一个初中魔方社团的临时章程，105条，18章，52处权力约束机制。

---

## 这是什么

一份由初中生撰写的社团章程——但读起来像一部微型宪法。

组织当前为非官方状态。一旦获得学校认可并签署合同（即"官方化"），名称中的"非官方"三字即可摘除，转为正式学生组织。若学校未来因分裂或招生不足而关闭，组织自动转为本县魔方协会，向民政局申请社会团体登记。

## 架构

```
全体成员会议（最高权力）
  ├── 常任委员会（日常执行）
  ├── 组织代表（临危决断）
  ├── 监察委员会（独立合规审查）
  ├── 经费管理委员会（独立管账，直接对全会负责）
  ├── 历史管理委员会（记录传承）
  ├── 安全管理委员会（活动安全）
  ├── 运营小组（线上网站与平台维护）
  └── 联络员制度（为无法上网者传递信息与代为投票）
```

## 核心特征

- **权力分散：** 管账的不花钱（经费委），花钱的不记账（常任委），查账的不管钱（监察委）
- **自我纠错：** 52处约束分布在105条中——从24小时会议通知到被否提案14日冷却，从利益回避到代号匿名投票
- **分阶段演进：** 初创期由临时发展工作组集体代行决策权，创始人任召集人；满15人召开第一次全体成员会议；会后14日内完成所有机构的选举，工作组随即解散
- **信息防垄断：** 联络员制为不能上网的成员传话收票；档案可公开部分主动公开

## 文件结构

仓库按「文档 / 脚本」两层组织；文档内部按文件用途（类型）分类。

```
仓库根/

│   ├── import_charter.py     从 Markdown 非破坏性推送（UPSERT）到 charter.db
│   ├── export_charter.py     从 charter.db 导出 Markdown（带时间戳防覆盖）
│   └── build_disciplinary.py 违规处罚规则管理（建表 / 增改删查）
└── 文档/
    ├── 规范性文件/           章程与细则（组织运行的约束性文件）
    │   ├── xssz魔方非官方组织临时章程.md（+.pdf）   主章程，105条18章
    │   ├── 全体成员会议工作临时细则.md（+.pdf）
    │   ├── 常任委员会运作临时细则.md（+.pdf）
    │   ├── 监察委员会调查程序临时细则.md（+.pdf）
    │   ├── 经费管理委员会临时细则.md（+.pdf）
    │   ├── 特殊身份临时细则.md（+.pdf）
    │   ├── 历史管理委员会临时细则.md（+.pdf）
    │   └── 运营委员会临时细则.md
    ├── 发布/                 对外发布的版本
    │   ├── 发布-临时章程.md（+.pdf）
    │   └── 发布-特殊身份临时细则.md（+.pdf）
    └── 参考资料/             草案、补充决议、过程分析
```

所有文件均为**临时**版本，待第一次全体成员会议通过正式版本后自动废止。
